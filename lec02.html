2  表を読む

データの形を知る

Note今日の問い

このクラスは、どんな集団なのでしょうか？

前回、皆さんに受講生アンケートに答えてもらいました。今日はその結果をExcelで開いて眺めてみます。

今日使うデータは、Excelファイル「課題_2」に入っています。皆さんが前回答えたアンケートの結果を、回答そのまま入れてあります（名前や学籍番号は入っていません）。

「オリジナルデータ」「作業データ」とシートが2つありますが、同じデータです。「作業データ」に作業を行い、途中で間違ってデータを消してしまったりした場合には、「オリジナルデータ」からコピーしてデータを修復してください。

2.1 Excelの基本

2.1.1 画面の名前を覚えよう

Excelを開くと、マス目がたくさん並んだ画面が出てきます。まずは、次の言葉を覚えましょう。

用語 意味
ブック Excelのファイル1つのこと
シート ブックの中のページ。画面下のタブ（「Sheet1」など）で切り替える
セル マス目の1つ1つ
行 横の並び。左端の数字（1, 2, 3, …）で表す
列 縦の並び。上端のアルファベット（A, B, C, …）で表す
セル番地 セルの住所。列と行の組み合わせで「B3」のように表す

セル番地は「列（アルファベット）→行（数字）」の順で書きます。「B3」は、B列の3行目のセルです。この書き方は、次回から関数を使うときに必ず出てきます。

2.1.2 基本の操作

  • セルを選ぶ：クリックします。選んだセルは緑の枠で囲まれます。
  • 範囲を選ぶ：セルをクリックしたまま、ドラッグします。
  • 列全体を選ぶ：列の上のアルファベット（例：「C」）をクリックします。
  • 列の幅を広げる：列のアルファベットの境目をダブルクリックすると、中身に合わせて幅が自動で調整されます。
  • 元に戻す：失敗したら Ctrl + Z（Macは command + Z）。何度でも戻せるので、安心していろいろ試してください。

2.2 データの「形」を知る

2.2.1 1行＝1人、1列＝1つの質問

アンケートのファイルを開くと、次のような表になっています（値は架空の例です）。

回答番号 学年 通学時間（分） スマホ時間（時間） 政治への関心
1 2年 60 4.5 ある程度関心がある
2 1年 90 3 あまり関心がない
3 3年 25 6 まったく関心がない

この表には、データ分析でとても大切な「決まり」があります。

  • 1行が1人分の回答になっている。この「1行が表すもの」を観測単位（ケース）と呼びます。
  • 1列が1つの質問（特徴）になっている。この列のことを変数と呼びます。
  • 一番上の行（1行目）には、変数の名前が書かれている。

観測単位は、いつも「人」とは限りません。都道府県別のデータなら1行＝1つの都道府県、年ごとのデータなら1行＝1年です。新しいデータを見たら、まず「1行は何を表しているか？」を確かめる習慣をつけましょう。

2.2.2 量的データと質的データ

変数には、大きく分けて2つの種類があります。

種類 特徴 例
量的データ 数の大きさに意味がある。足したり平均したりできる 通学時間、スマホ時間、年収、人口
質的データ 種類やグループを表す。平均しても意味がない 学年、性別、都道府県名、「賛成・反対」

質的データの中には、「関心がある → ない」のように順序があるものもあります。ただし、順序があっても「ある」と「ややある」の差が、「ややある」と「あまりない」の差と同じとは限りません。

Importantなぜ種類を区別するのか？

データの種類によって、使える計算やグラフが変わるからです。例えば、通学時間は平均を計算できますが、学年を「平均2.4年生」と計算しても、あまり意味はありません。学年は「何年生が何人いるか」を数えるのが自然です。

2.3 並べ替えとフィルター

表を眺めるときに便利な2つの機能を覚えましょう。

2.3.1 並べ替え（ソート）

データを、ある変数の大きい順・小さい順に並べ替えます。

  1. 表の中のどこか1つのセル（例：A2）をクリックします。
  2. 上のリボンの「データ」タブをクリックします。
  3. 「並べ替え」をクリックします。
  4. 「最優先されるキー」で、並べ替えたい列（例：「通学時間（分）」）を選びます。
  5. 「順序」で「大きい順」または「小さい順」を選び、「OK」を押します。
Important並べ替えの注意

1つの列だけを選んで並べ替えてはいけません。その列だけが並び替わり、他の列とずれてしまい、1行＝1人の対応が壊れてしまいます。必ず表の中の1つのセルを選んだ状態で「並べ替え」を使いましょう。おかしくなったら、すぐに Ctrl + Z で戻します。

2.3.2 フィルター

条件に合う行だけを表示します。データは消えずに、見えなくなるだけです。

  1. 表の中のどこか1つのセルをクリックします。
  2. 「データ」タブ → 「フィルター」をクリックします。
  3. 1行目の変数名の右に「▼」ボタンが表示されます。
  4. 例えば「学年」の「▼」をクリックし、「すべて選択」のチェックを外してから「1年」だけにチェックを入れて「OK」を押します。
  5. 1年生の行だけが表示されます。画面左下（ステータスバー）に「○件中△個のレコードが見つかりました」と表示されます。

フィルターを解除するには、もう一度「データ」タブ → 「フィルター」をクリックします。

Tip便利な小技：ステータスバー

数値が入ったセルの範囲をドラッグで選ぶと、画面右下に「平均」「データの個数」「合計」が表示されます。関数を使わなくても、ざっと数字を確かめられます。

2.4 データを整える

2.4.1 集めたままのデータは「乱れて」いる

皆さんのアンケートを集めてみると、次のような回答がありました（一部です）。

質問 回答 何が問題？
通学時間
（分）		 30分 「分」が付いていて、数値として計算できない
睡眠時間
（時間）		 ７時間 全角の数字は、Excelでは文字として扱われる
前期GPA 1,5 小数点がカンマになっている
スマホ時間
（時間）		 10以上 1つの数値になっていない
Excel経験 ある 選択肢にない書き方で、どの選択肢か判断できない

人間が見れば意味は分かります。しかしExcelは「30分」を数値ではなく文字として扱うので、平均を計算したり、大きい順に並べ替えたりできません。「あまり関心がない」と「あまりない」も、別のグループとして数えられてしまいます。

このように、集めたばかりの生データには、そのままでは計算や集計ができない回答がよく混じっています。

Important分析の前に、まずデータを整える

データ分析の作業の多くは、実はこの「整える」作業です。整えないまま分析すると、人数の数え漏れや、間違った平均につながります。

2.4.2 直し方のルールを決める

乱れの例 直し方の例
「30分」「７時間」 単位を取り、半角の数値にする（30、7）
通学時間が「1時間」 質問の単位（分）にそろえる（60）
「1,5」 小数点に直す（1.5）
「10以上」「3〜4」 ルールを決める（例：「以上」はその数値、範囲は真ん中の値）
「わからない」など 空欄にする

直し方に唯一の正解はありません。大切なのは、ルールを決めて、どう直したかを記録しておくことです。そうすれば、他の人が結果を確かめたり、同じ作業をやり直したりできます。

2.4.3 乱れを見つけるコツ

  • フィルターの「▼」で値の一覧を見ます。数値の列なら「分」などが付いた回答が、選択肢の列なら違う書き方が目立ちます。
  • 小さい順に並べ替えると、文字として入っている回答は、数値の下にまとまります。

課題_2の「作業データ」シートには、こうした乱れが8か所残っています。演習では、まずこれを見つけて直してから、分析に進みます。

2.5 課題_2に取り組もう

Excelファイル「課題_2」を使って作業します。作業したファイルが、そのまま今日の課題の提出物になります。

Important課題_2の進め方
  1. Blackboardから 課題_2.xlsx をダウンロードして開きます。
  2. 最初のシート「はじめに」に、学籍番号と氏名を入力します。
  3. シートを順番に進めます。黄色のセルが、皆さんが入力する場所です。
  4. 最後に、ファイル名を 課題_2_氏名.xlsx に変えて保存し、Blackboardに提出します。
シート 内容
はじめに 学籍番号・氏名の入力、進め方の説明
オリジナルデータ クラスのアンケート結果（1行＝1人、回答そのまま）。消してしまったときの予備
作業データ オリジナルデータと同じ内容。作業はこちらで行う
1_データを整える 分析できない回答を8か所見つけて直し、直し方を記録する
2_変数の分類 各変数が量的データか質的データかを分類する
3_並べ替え 並べ替えを使って、最大・最小を調べる
4_フィルター フィルターを使って、学年別・Excel経験別の人数を数える
5_データの取得 乱れを防ぐアンケートを考える、公開データを整える
6_データの分析 今回のデータを使い自分でデータを分析する
7_振り返り このクラスの特徴、身近なデータの観測単位と変数

基本課題は「1_データを整える」〜「5_データの取得」と「7_振り返り」です。「6_データの分析」は、自分のレベルに応じて（Excelの慣れに応じて）取り組んでください。できる人は、グラフをつくる、相関を分析するなどトライしてみてください。

Tip解答

2_変数の分類の答えです（授業の最後に確認しましょう）。

変数 種類 補足
回答番号 どちらでもない 人を区別するための番号。大きさに意味はない
学年 質的 順序あり
通学時間（分） 量的
スマホ時間（時間） 量的
睡眠時間（時間） 量的
朝食日数（日） 量的 0〜7の整数だけをとる
政治への関心 質的 順序あり（5段階）
選挙経験 質的
Excel経験 質的 順序あり
クイズ正解数 量的 0〜5の整数だけをとる
前期GPA 量的 小数をとる
  • ポイント：回答番号は数字ですが、大きさに意味はありません（3番の人が1番の人の3倍、ということはない）。数字で書かれていても量的データとは限りません。
  • 1_データを整える、3_並べ替え、4_フィルターの答え合わせは、授業中に行います。

2.6 共有：このクラスはどんな集団？

「6_データの分析」ができた人は、周りの人に結果を共有してください。

2.7 振り返り

Note今日のまとめ
  • データは「1行＝1観測単位、1列＝1変数」の形に整えると分析しやすい。
  • 変数には量的データと質的データがあり、種類によって使える計算やグラフが変わる。
  • 並べ替えとフィルターで、表を眺めるだけでも多くのことが分かる。
  • 集めたままのデータには乱れがある。分析の前に、ルールを決めて整える。
